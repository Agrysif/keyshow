# Промо-ролик KeyShow

20-секундный ролик 1920×1080, 60 к/с: 3D-интро на Three.js, настоящий движок KeyShow в работе,
монтаж стилей, 12 языков и финальная плашка. Смены сцен стоят на долях бита трека.

## Музыка

«Uplifting Bass» — Lily J, [Mixkit](https://mixkit.co/free-stock-music/tag/technology/)
(Mixkit Stock Music Free License: можно в YouTube, соцсетях и онлайн-рекламе, указывать автора не обязательно;
нельзя на CD/DVD, ТВ и радио, в играх и отдельным музыкальным треком).

Трек не хранится в репозитории. Скачайте его в `promo/music/uplifting-bass.mp3`:

```bash
curl -L -o promo/music/uplifting-bass.mp3 https://assets.mixkit.co/music/726/726.mp3
```

Используется отрезок с 10,761 с (134 BPM) — так дроп приходится на 8-ю долю, когда нажимаются клавиши KEYSHOW.

## Рендер

Нужен `ffmpeg` в PATH.

```bash
npx electron promo/render.js
```

Готовое видео — `promo/out/KeyShow-promo.mp4`. Флаги:

- `--blur 3` — размытие движения из N подкадров (по умолчанию 3, `--blur 1` — без него, быстрее);
- `--stills 1,3.6,8` — только PNG-кадры на указанных секундах в `promo/out/stills`;
- `--dbg` — показать в кадре время и состояние курсора.

## Как устроено

- `clock.js` — виртуальные часы: подменяют таймеры, `performance.now` и анимации, чтобы каждый кадр
  считался ровно в свой момент. В угол кадра ставится метка с номером кадра — рендерер ждёт снимок
  с нужной меткой (окно без экрана отдаёт кадры с запаздыванием) и затем закрашивает её.
- `promo.js` — сценарий: 3D-сцены, события клавиатуры и мыши для движка KeyShow, подписи.
- `render.js` — Electron-окно без экрана 1920×1080 → сырые кадры → ffmpeg (H.264 + AAC).
