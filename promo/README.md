# Промо-ролик KeyShow

Ролик ~24,5 с, 1920×1080, 60 к/с. Смены сцен стоят на долях бита трека:

- 3D-вступление на Three.js: макросъёмка клавиатуры с подсветкой и глубиной резкости. Слово KEYSHOW
  набирается по клавише на долю, и каждое нажатие тут же показывает настоящий оверлей KeyShow.
- Моушен на нарастании: слово из клавиш, поток сочетаний, брейк «Ты нажимаешь — зритель видит»
  и клик курсора на дропе — волна заливает экран синим, клавиши разлетаются, слоган.
- Настоящий движок KeyShow в работе: сочетания, 3–4 клавиши, мышь, тряска курсора.
- Монтаж стилей, 12 языков и финальная плашка с 3D-иконкой на последнем ударе трека.

## Музыка

Трек сгенерирован в Suno специально под ролик (128 BPM, первая доля 0,406 с, дроп 7,906 с,
финальный удар 22,22 с). В репозитории он не хранится — положите его в `promo/music/keyshow-suno.mp3`
или укажите свой файл флагом `--music`.

## Рендер

Нужен `ffmpeg` в PATH.

```bash
npx electron promo/render.js
```

Готовое видео — `promo/out/KeyShow-promo.mp4`. Флаги:

- `--blur 3` — размытие движения из N подкадров (по умолчанию 3, `--blur 1` — без него, быстрее);
- `--stills 1,3.6,8` — только PNG-кадры на указанных секундах в `promo/out/stills`;
- `--music path.mp3` — другой трек;
- `--dbg` — показать в кадре время и номер доли.

## Как устроено

- `clock.js` — виртуальные часы: подменяют таймеры, `performance.now` и анимации, чтобы каждый кадр
  считался ровно в свой момент. В угол кадра ставится метка с номером кадра — рендерер ждёт снимок
  с нужной меткой (окно без экрана отдаёт кадры с запаздыванием) и затем закрашивает её.
- `promo.js` — сценарий: 3D-сцены, события клавиатуры и мыши для движка KeyShow, подписи.
  Время задаётся в долях: `T(n)` — момент n-й доли трека.
- `render.js` — Electron-окно без экрана 1920×1080 → сырые кадры → ffmpeg (H.264 + AAC).
